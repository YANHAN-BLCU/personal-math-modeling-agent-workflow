# 论文章节模板

章节名称和顺序首先服从当届官方模板。官方没有固定章节时，默认采用以下正文结构：

1. 问题重述
   - 1.1 问题背景
   - 1.2 问题提出
2. 问题分析
   - 2.1 问题一的分析
   - 2.n 问题 n 的分析，按实际子问题逐项展开
3. 模型假设
4. 符号说明
5. 模型准备
6. 各问题模型建立及求解，按问题一、问题二、问题三等分别设章或设节
7. 灵敏度分析
8. 模型的评价与推广

标题、摘要、关键词置于正文之前，参考文献和官方允许或要求的附录置于正文之后。若题目类型或论证逻辑存在明显更合适的结构，先向用户提出替代框架及理由，再按用户选择定稿。

## 摘要

摘要应直接回答：解决了什么问题、采用什么模型、得到哪些实际数值结果、如何验证、结论适用于什么条件。篇幅、关键词、摘要页和编号完全按当届官方规则。

## 问题重述与分析

用自己的语言说明任务、输入、约束和输出，不能虚构背景数据。问题分析应解释为何选择当前模型以及模型如何对应题目结构。

## 模型建立与求解

每个子问题最多两个独立模型体系；同一物理机制的基础近似和高精度展开按一个模型族组织。按“变量与参数 → 假设依据 → 数学定义 → 算法 → 运行参数 → 实际结果 → 验证”展开。模型选择以题目适配和证据为准。

## 结果分析

每个主张紧跟真实表格、图或数值输出。置信区间、p 值、误差和改进幅度都由代码计算，并与复现清单一致。

## 模型评价

说明优点、局限、失败条件和可推广范围。局限必须来自假设、数据、算法或验证结果。

## 参考文献

正文引用与文末条目双向对应。作者、题名、年份、来源、卷期页和 DOI 以原始出版页面为准；双引擎搜索只用于发现和交叉核验。
